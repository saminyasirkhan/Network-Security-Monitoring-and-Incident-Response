# 🛡️ Network Security Monitoring & Incident Response

This project focuses on designing a **network security monitoring and incident response strategy** for a fictional organisation operating in the defence and security sector.

It explores how intrusion detection systems, network traffic analysis, endpoint security and centralised security monitoring can be integrated to identify insider threats, detect suspicious activity and support digital forensic investigations.

## 📄 Project Overview

The project evaluates the security requirements of a segmented enterprise network and proposes a layered monitoring architecture to improve threat detection, incident response and operational resilience.

**Key areas explored:**
- Network reconnaissance and insider threat detection
- Intrusion Detection Systems (IDS)
- Network traffic monitoring and security analytics
- Security Information and Event Management (SIEM)
- Endpoint Detection and Response (EDR)
- Digital evidence collection and forensic integrity
- Advanced Persistent Threat (APT) detection
- Security infrastructure scalability and cost effectiveness

## 🔍 Key Components

### 1. Network Monitoring & Threat Detection
- Identified strategic monitoring locations across a segmented enterprise network.
- Proposed Suricata and Zeek sensors for detecting suspicious network activity.
- Evaluated NetFlow/IPFIX for identifying reconnaissance and anomalous traffic patterns.
- Explored SIEM and EDR integration for correlating network and endpoint security events.

### 2. Intrusion Detection System Evaluation
- Compared Snort and Suricata across protocol analysis, content matching, performance and maintenance.
- Recommended Suricata for its structured EVE JSON logging and SIEM integration capabilities.
- Evaluated operational trade-offs involving detection performance, resource consumption and scalability.

### 3. Incident Response & Digital Forensics
- Analysed a hypothetical security incident involving USB activity, unusual file access and high-volume database communications.
- Proposed procedures for collecting network and endpoint evidence.
- Applied NIST SP 800-86 principles to forensic evidence preservation, integrity verification and chain of custody.

### 4. Advanced Persistent Threat Detection
- Proposed techniques for detecting low-and-slow reconnaissance and suspicious lateral movement.
- Evaluated monitoring effectiveness through vulnerability scanning, penetration testing and stress testing.
- Considered behavioural baselines and security telemetry correlation.

### 5. Security Investment & Operational Considerations
- Assessed monitoring infrastructure, software and personnel requirements.
- Evaluated scalability, data retention, privacy and operational costs.
- Considered security investment, analyst training and long-term monitoring effectiveness.
